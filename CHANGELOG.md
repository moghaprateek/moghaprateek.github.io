# Changelog

All notable changes to this portfolio. Newest first. Versions follow `major.minor.patch`.

## 1.7.0 - 2026-10-13
- Two-column layout: one wide fixed sidebar on the left (intro, skills, then education and certifications side by side). The content on the right is the only part that scrolls.
- Mobile intro card: the four buttons (Email, LinkedIn, GitHub, CV) now sit in one row with the icon on top and the label underneath, so text no longer overlaps.
- Sidebar gets a thin scrollbar and a bottom fade on short screens.

## 1.6.0
- Floating pill menu on desktop and an iOS-style bottom tab bar with icons on phones.
- Wider desktop layout (up to 1680px); projects and GitHub projects side by side on very wide screens.
- Experience bullets collapse after 5 per role with "Show more" and "Show less" (`visibleBullets` in `config.js`).
- Phone refinements: shorter intro card, single-row scrolling filter, collapsible Skills and Certifications, logo and theme button hide on scroll, 44px tap targets, fewer floating symbols.

## 1.5.0
- Developer theme: near-black background, emerald accent, grid, floating code symbols, `//` headings and a `$ whoami` intro.
- Projects and GitHub projects shown as minimal lists (number, name, description, tags, arrow).

## 1.4.0
- Glass-style cards with reduced transparency and blur.
- Light mode toggle, remembered per visitor.

## 1.3.0
- All content moved into `config.js` so updates do not need HTML edits.
- README rewritten with update instructions.
- Empty lists in `config.js` hide their section and menu link.

## 1.2.0
- Search and sharing support: title, description, keywords, canonical URL, Open Graph and Twitter tags, JSON-LD, `og-image.png`, `robots.txt`, `sitemap.xml`.
- Download CV button with `Prateek_Mogha_CV.pdf`.

## 1.1.0
- GitHub projects section added from public repos.
- YouTube link removed; GitHub, LinkedIn and email links set.

## 1.0.0
- First release: three-column dashboard with fixed side panels, experience timeline with theme filters, work projects, education, certifications and contact section.
- Responsive layout for tablets and phones.
